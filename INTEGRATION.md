# Integration Instructions

1. Replace the repository root `README.md` with the included `README.md`.
2. Copy the included `docs/` directory to the repository root.
3. Keep the existing `LICENSE`, `CHANGELOG.md`, `CONTRIBUTING.md` and Postman assets.
4. Review repository owner/URL values in README badges if the GitHub repository slug changes.
5. Commit the change, for example:

```bash
git add README.md docs
git commit -m "docs: add project documentation suite"
```
